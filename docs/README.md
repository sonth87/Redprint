# Tài liệu My Builder

Chào mừng bạn đến với tài liệu của **My Builder** — thư viện xây dựng giao diện web (landing page)
bằng kéo-thả, có AI hỗ trợ tạo trang tự động.

## Tài liệu này dành cho ai?

| Bạn là | Đọc gì |
|--------|--------|
| Người dùng editor / PM / người mới vào dự án | 👉 [user-guide/](./user-guide/01-gioi-thieu-tong-quan.md) — tiếng Việt, dễ hiểu, có sơ đồ luồng |
| Dev / AI agent cần đặc tả kỹ thuật chi tiết | 👉 [`.claude/docs/`](../.claude/docs/README.md) — English, code-level, type contracts |
| Người lập kế hoạch / theo dõi tiến độ cải tiến | 👉 [roadmap/](./roadmap/README.md) — kế hoạch chi tiết từng hạng mục |

4. [Components & Preset](./user-guide/04-components-va-preset.md) — các khối dựng trang có sẵn
5. [Styling & Hiệu ứng](./user-guide/05-styling-va-hieu-ung.md) — bộ lọc ảnh, khung, đổ bóng, animation, hover

## Quy ước

- `/docs` (thư mục này): tài liệu **cho người dùng**, tiếng Việt.
- `.claude/docs`: tài liệu **đặc tả cho AI agent & maintainer**, tiếng Anh, chi tiết hơn.
- `docs/roadmap`: kế hoạch cải tiến — mỗi hạng mục một file, có trạng thái theo dõi.
- Tài liệu mô tả **trạng thái hiện tại** của sản phẩm; tính năng đang phát triển được ghi chú kèm link roadmap.
